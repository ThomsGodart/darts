# Scope

**Audited:** Existing Flutter UI in `lib/` (X01 Session scorer) — not wireframes, not future Cricket/Killer screens.

**Surfaces:** Home, Setup, Game (scoreboard + visit input + game over), History, PersistFailureBanner, theme `default`.

**Primary user:** Dart player in a shared-phone soirée (standing at the oche / reading from 2–3 m).

**Primary task:** Enter a visit and read remaining / whose turn — as few taps as possible, offline.

**Constraints:** Flutter, Material, French UI, offline-first, theme tokens `DartsTokens`, roadmap polish deferred to jalon v1.4.

**Competitors / refs:** MyDartTraining (dense, ads), Compteur de Fléchettes (simpler).
